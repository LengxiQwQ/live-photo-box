v2.2.0 What's New

New:
- 🖼️ Full HDR support — HDR survives protocol conversion; Apple and Google gain maps convert both ways
- 🔗 Split page redesigned to mirror the Merge page — batch split and protocol conversion in one place: protocol, output format, naming templates, overwrite policy, and after-completion actions
- 📱 New Apple Live Photo protocol — split output can be written as Apple dual-file (photo + MOV) with paired metadata; due to iOS restrictions, import via third-party tools such as 爱思助手 (i4Tools)
- 📱 vivo Live Photo protocol (in testing, ≤ X200) — output as JPG + MP4 dual-file pairs; feedback welcome if it works on your vivo phone
- 📤 Lossless HEIC splitting — 10-bit depth, HDR gain map, and original metadata are kept intact

Optimized:
- 🧹 Fusion protocol temporarily retired — the author's universal format (aimed at any-device playback) needs more polishing and will return later

💡 CLI mode ships with the GitHub release only — the Store version does not include it. Download from GitHub Releases if you need it.
