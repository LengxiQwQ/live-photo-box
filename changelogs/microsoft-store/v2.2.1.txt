v2.2.1 What's New

New:
- 🔔 System notifications — get a Windows notification when batch processing finishes; click to jump to the page. Frequency and sound are customizable in settings (always / after a duration / never)
- 📊 Taskbar progress — the taskbar icon shows real-time progress while processing, flashing at completion
- 💡 Interactive guided tutorial — step-by-step tooltips on Merge and Split pages help first-time users get started

Optimized:
- 🖼️ Window width/height remembered; window always opens centered
- 🎨 Repair page status bar unified across all three pages
- 📋 Queue improvements — only one queue runs at a time; failed tasks show a compact hint with full details on tap
- 🖱️ Merge/Split splitter resizes proportionally to fit any window size
- 🧹 Protocol ComboBox text left-aligned, sample content grayed out, unused settings cleaned up

Fixed:
- 🛠️ Queue identification skipping, Lightbox playback, subfolder scanning, output directory not auto-set when adding files
- 🔧 CLI channel display and portable-mode notification activation
