## 2. 当前架构理念

### C# = Control Plane

负责：
- GUI / CLI；
- workflow / orchestration；
- request / result；
- progress；
- cancellation；
- workspace；
- 上层产品流程。

### C++ Native = Data Plane

负责：
- JPEG；
- HEIF / HEIC；
- EXIF / TIFF；
- XMP；
- MakerNote；
- ISO-BMFF；
- MP4 / MOV；
- Samsung SEF；
- 来源协议识别；
- 媒体范围确认；
- 提取；
- 协议清洗；
- metadata/container rewrite；
- 图片/视频转换。

### 当前原则

```text
Source-first
Structure-first
Safety-first
Neutral-media-first
Writer-last
```

无法安全确认结构时：宁可拒绝，也不要猜 offset，更不能破坏源文件。

当前中性化思路：

```text
Source
→ Inspector
→ Extractor
→ Cleaner
→ Converter
→ Neutral Media
```

Target Protocol Writer 后置。

## 4. README 必须重写为当前事实

README 不再把以下内容描述为当前架构：

- Legacy / Rebuilt backend switch；
- `lpb backend`；

- `Tools/` / `Tools/bak/` 作为当前正式运行目录；

README 应至少包含三类信息。

### 4.1 当前架构

明确：

```text
GUI / CLI
→ Core orchestration
→ Native C++
```

并明确：

```text
No Legacy Runtime
No Bundled External Media Executables
```

### 4.2 当前开发状态

当前 master 属于 Native-only 重构主线。

部分历史 Release 已有功能在当前 master 中可能暂时未开放，包括：
- Cover；
- Repair；
- 部分 HEIC target writer；
- Apple target writer；
- target-protocol split / repackaging。

不能把这些写成当前 master 已完整支持。

### 4.3 历史版本说明

必须保留简短历史说明，解释旧 Release 为什么不同。

推荐中文语义：

> Live Photo Box 的部分历史发布版本曾使用 FFmpeg、ExifTool、jpegtran 和 libheif 命令行工具完成部分媒体与元数据处理。当前开发主线已经迁移至 Rebuilt / Native-only 架构，这些外部可执行工具不再属于当前产品运行时设计。因此，旧发布版本与当前 master 在目录结构、依赖和部分功能可用性上可能存在差异。

推荐英文语义：

> Earlier Live Photo Box releases used bundled external tools such as FFmpeg, ExifTool, jpegtran and libheif command-line utilities for parts of the media and metadata pipeline. The current development branch has moved to a Rebuilt / Native-only architecture, and those external executables are no longer part of the current product runtime. As a result, older published releases may differ from the current master branch in dependencies, architecture and temporary feature availability.

允许优化措辞，但含义必须保留。
