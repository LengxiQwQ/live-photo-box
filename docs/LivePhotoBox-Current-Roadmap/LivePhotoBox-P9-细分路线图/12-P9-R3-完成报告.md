## 改了什么

- Google V1 依据实际文件尾部计算视频偏移、版本和封面微秒。V2 合并唯一标准 XMP，按实际 Primary/GainMap/Original/MotionPhoto 图计算 MIME、长度、padding 与位置；不依赖旧 V1 字段定位。OPPO 写入并独立比对 owner、版本、VideoLength、UserComment 和原始/当前两个时间；未知原始时间不能用当前封面或零冒充。
- 原有普通 XMP、Exif、ICC、MakerNote、合法未知字段与编码字节保留。支持合法 Primary 目录、自闭合 RDF、Extended XMP 的完整分块/MD5/唯一引用；重复、shadow、错误归属和隐藏 live binding 继续拒绝。RELEASE-004 精确原图在全部五个适用 JPEG 目标/容器组合生成唯一目标包。
- GainMap、Original、MiCamera 子图与水印通过真实 Neutral 身份、owner、selector、relationship 和 hash 接通。已有嵌入资产与同一 materialized 镜像只放一次。Original 中的历史 XMP 和其自有嵌套 GainMap 原字节保留，不作为外层 placement 权限。MPF 扩表保留原索引及未知字节，只更新明确的派生字段。
- HEIC+MOV 通过项目自有 item graph 重写 XMP 和位置，保留非 XMP item、属性及编码数据；按实际 8/16 字节 mpvd 头计算位置。检查 HEIC 主品牌以及实际 primary/derived grid 的 HEVC 依赖，不把 generic HEIF 或伪 AVIF 当作已支持的 HEIC。
- 按用户决定，未转换图片时允许小米等源的方向为 Unknown，保留非法 LONG/0 的原始字段和主图字节，不猜成 0°，不旋转、重编码或伪装 Verified。已知方向继续严格比对；格式转换的方向保留前提保持严格。
- 视频改为 64 位流式复制，去掉实验链原先整段视频 256MiB 快照限制。普通 mdta、未知 UUID 与有界普通顶层数据保留；已知 live key、错误父子归属及 duplicate 继续拒绝。CICP 的 transfer 1/6 等价按实际标准处理，原 container/SPS 字节均保留，真实冲突仍拒绝。
- 配套 ABI15，保留既有 v1 POD 与导出，新增 prepareV2/validateV2 两个生产入口，分别携带完整扩展语义和独立观察。生产导出 82 项，测试专用导出不进入生产 DLL。
