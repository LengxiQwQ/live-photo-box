# P4-R3 Native dependency identity

The canonical Windows x64 Native image dependencies are declared in `vcpkg.json`. Its built-in Microsoft vcpkg registry baseline is pinned to commit `9e44ec0e9f247d77c230ced0ee66c76296837807`. These dependencies are resolved through vcpkg manifest mode and CMake imported targets; they are not manually added to `.vcxproj` or machine library paths. The approved video sidecar uses a separate pinned-source build described below; it is not a vcpkg manifest dependency.

| Dependency | Source/version | Features / disabled | Linkage/runtime | License | Why |

R5 removed `windowscodecs` and `shlwapi` from the Native link graph; WIC is not a result-affecting image codec dependency. |

The image manifest uses no `FetchContent` or local codec patch. The video prerequisite scripts pin source archives, configure arguments and the x265 overlay identity; the build verifies their records rather than selecting floating system libraries. Current records are under `.ai-tmp/workspace/P7/R4-large-batch-soak/hevc-migration/`. Non-Windows portable-core smoke is available independently; a non-Windows production build still requires approved platform/media backends and verification.
