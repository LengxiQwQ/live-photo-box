## 已按冻结手册确认

- [x] **开始/停止按钮**：拆分开始后主按钮显示“停止”，结束/取消后恢复“开始拆分”；停止中的提示与实际状态一致。使用现有工作副本即可，不必验证所有输出格式。
- [x] **暂停提示**：暂停后队列不继续启动新任务，恢复入口可见。提示不再无根据地宣称 NVENC/某硬件正在执行；结果详情中的 backend 才对应该次实际执行。暂停前已运行任务可以先结束，这是正常的排空过程。
- [x] **新任务与页脚**：保留一次已完成任务后添加新 Pending 项，主按钮允许开始新一轮，页脚不沿用旧的“全部完成”文字；已成功项不被当作本轮重新处理。两轮处理和源文件动作已有实操证据，此处重点看最终页脚修复。
- [x] **结果详情**：成功、明确不支持及取消显示的路径/状态与任务相符；失败或取消不能显示虚构的已提交产物。准备阶段的保留证据与最终目标 `Unknown` 含义区分清楚，不能把 Unknown 理解成目标结构通过。
