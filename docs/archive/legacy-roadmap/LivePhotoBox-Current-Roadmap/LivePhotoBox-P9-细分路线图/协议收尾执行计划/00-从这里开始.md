## 2. 用户已经决定的事（不要再讨论）

1. **A 级正确是主线。** 完整图片/视频、有效声音及同步、方向/镜像、封面对应、目标结构、基础颜色和安全正确；不是字段和字节全保留。
2. **兼容档用于正常转换。** 按实际媒体及目标能力复用或转换，允许图片/音视频转码、重封装与合理位深转换；不按来源品牌分路，也不统一裁掉所有辅助内容。
3. **音频保证正常内容与同步。** 需要时转目标支持编码；既有有效声道处理继续复用，不以原始编码/容器/逐包字节不一致拒绝普通转换。
4. **B 级现成能带就带。** 常见 EXIF/ICC/HDR/Gain Map 不要求全部补齐。HDR 无法可靠保留可正确转 SDR 并记录，不自动排入后续任务；HDR 专项由用户决定。
5. **C 级明确退出。** 无关私有轨、编辑历史、Original、缓存、填充等不要求跨协议保留，不新增 ABI/封装/Writer/证明系统；私有记录里的 A 语义仍需提取处理。
6. **先检查成品，可分批试机。** 每个交付样本本身必须完整、电脑检查有效；其他组合失败/未覆盖不妨碍该样本先试机，清单不得冒称全来源整包通过。A 缺陷保留并修复，不推给用户测坏文件。
7. **按影响测试，不死磕。** 日常定向验证，收口补必要全面验证，按 03 复用有效结果。先分 A/B/C，再按根规则 0.2 的无进展提醒线报告；B/C 不长时间试错。
8. **保留既有目标顺序，不新增阶段。** 小米/Google → OPPO/一加 → Apple → 旧 vivo → 商场组 → Fusion；缺设备保持未测，不把所有前序来源/设备结果齐全当作开始后续目标设备测试的门槛，推进仍须用户授权。
9. **已有成果留存。** Strict 显式能力及有效测试不删、不改松；其中额外保留拒绝不成为普通转换/P9 门槛，不再强制 B 轮。
10. **小米设备旧记录为在朋友处。** 不催取回、不强制诊断包；可准备有效样本，设备不可用即记未测。
11. **转码视频真正转正。** 按实际方向/镜像处理像素后归零旋转表示，避免二次旋转；不按品牌特判。
12. **到约定边界停下。** 每目标有效测试批次就绪或目标基础验收收口时报告，等用户继续；汇报不增加测试或审查。本次停在文档调整，不施工。

## 3. 不变的硬规则

- 架构不变：原始输入 → 来源识别/提取/精确清理 → Neutral → 目标媒体准备 → 结构化 Writer → 重开校验 → 安全发布。
- 目标规则可以按目标协议定；中间通用处理只按实际媒体语义分流，**禁止按来源品牌/型号/文件名/hash 写特判**。
- 交付成品只能由正式 CLI 生成；脚本只能调度 CLI、复制、出清单、做独立检查，不能自己改成品。
- 来源文件永远只读；发布失败不留半成品；双文件不能只发布一半。
- 不能把“没带过去”写成“已保留”；不能用电脑测试代替用户手机结果。
- 不自动 commit / push / tag / release，不进入 P10；任何提交或外部发布须当前用户明确授权。
