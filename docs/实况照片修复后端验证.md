## 实现

1. C# 共用服务负责诊断、按配对 ID 查找同伴、四项选项、源文件保护、临时产物验证、重名避让和新文件对发布。CLI 与 GUI 调用同一服务。禁止原地覆盖。
2. JPEG 使用现有 Native DCT 无损变换归一 EXIF 方向；不裁边，不重编码。清理已确认的 EXIF IFD1 缩略图引用及载荷，保留主图编码。HEIC 按主图 irot/imir 纠正冲突 EXIF，保留编码及容器显示变换。后续补齐 JPEG 已知段预览及 JFIF/JFXX 缩略图、HEIF 主图 thmb 缩略图及其独占依赖清理，详见下方 P10 收口。
3. MOV 修复使用现有最小 Libav 后端库，将主轨的旋转或水平/垂直镜像应用到帧，去除显示矩阵。保留编码种类及可用主音频；按源颜色、显示时间轴及几何信息验证。90/270 度同步交换像素比例及裁切边，避免拉伸和错误裁切。
4. 允许省略与基本播放无关的辅助和私有轨。重新写回原 Apple 配对 ID 和已确认的有效封面时间。封面未知时仅保留 ID，不编造时间，黄灯隔离。旧严格保留接口的精确保留含义不变。
5. 修复模式不自动触发现有 HLG → SDR 转换：能够保持必要颜色信息才导出通过；无法保留时说明原因。正常独立目标转换的既有 SDR 路径不变。
6. 修复页接回扫描、四项选择、输出目录、逐项结果和详情。两种输出模式均生成副本。CLI 的 --parallel 参数为兼容保留，目前文件对串行执行。
