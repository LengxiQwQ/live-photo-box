## 三、XMP 元数据

### 3.1 旧版 MicroVideo V1 XMP (12S Ultra)

```xml
<x:xmpmeta xmlns:x="adobe:ns:meta/" x:xmptk="Adobe XMP Core 5.1.0-jc003">
  <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
    <rdf:Description rdf:about=""
        xmlns:GCamera="http://ns.google.com/photos/1.0/camera/"
      GCamera:MicroVideoVersion="1"
      GCamera:MicroVideo="1"
      GCamera:MicroVideoOffset="1110663"
      GCamera:MicroVideoPresentationTimestampUs="459334"/>
  </rdf:RDF>
</x:xmpmeta>
```

字段:
- `GCamera:MicroVideo="1"` — 标识
- `GCamera:MicroVideoVersion="1"` — 版本
- `GCamera:MicroVideoOffset="{视频字节数}"` — 从 EOF 倒推
- `GCamera:MicroVideoPresentationTimestampUs="0"` — 微秒

### 3.2 新版 MotionPhoto V2 XMP (14 Pro)

```xml
<x:xmpmeta xmlns:x="adobe:ns:meta/" x:xmptk="Adobe XMP Core 5.1.0-jc003">
  <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
    <rdf:Description rdf:about=""
        xmlns:GCamera="http://ns.google.com/photos/1.0/camera/"
        xmlns:Container="http://ns.google.com/photos/1.0/container/"
        xmlns:Item="http://ns.google.com/photos/1.0/container/item/"
      GCamera:MotionPhoto="1"
      GCamera:MotionPhotoVersion="1"
      GCamera:MotionPhotoPresentationTimestampUs="1230275">
      <Container:Directory>
        <rdf:Seq>
          <rdf:li rdf:parseType="Resource">
            <Container:Item Item:Mime="image/jpeg" Item:Semantic="Primary"/>
          </rdf:li>
          <rdf:li rdf:parseType="Resource">
            <Container:Item Item:Mime="video/mp4" Item:Semantic="MotionPhoto"
              Item:Length="4424761" Item:Padding="0"/>
          </rdf:li>
        </rdf:Seq>
      </Container:Directory>
    </rdf:Description>
  </rdf:RDF>
</x:xmpmeta>
```

> 注意: Primary Item 没有 Item:Length 和 Item:Padding 属性（与现有的 MotionPhotoV2Protocol 不同）

## 五、APP3 + APP4 私有段

### APP3: ALGO_COMMON (~7-8 KB)
- 头: ALGO_COMMON + NUL + 版本标记
- 内容: ISP 算法处理二进制数据
- 可合成: 低

### APP4: XIAOMI_CUSTOMIZE (~500-700 B)
- 格式: XIAOMI_CUSTOMIZE + NUL + 00 01 01 + JSON
- 内容: 将 EXIF 私有标签值全部冗余存储一遍

```
{
  "8897": "1",
  "8895": "3",
  "10f": "Xiaomi",
  "88a3": "{}",
  "version": "30",
  "110": "Xiaomi 14 Pro",
```

## 六、0x889e JSON 完整内容

### 旧版 (12S Ultra, version:1)
```json
{
  "buildDevice": "thor",
  "customize": "",
  "livephotoInfo": "",
  "version": 1,
  "waterLogo": "..."
}
```

### 新版 (14 Pro, version:2)
```json
{
  "buildDevice": "shennong",
  "customize": "",
  "cvLensName": "",
  "filterName": "",
  "livephotoInfo": "head:866476912292 time:866478462780 tail:866480252292 filterId:327682 onlyPreDuration:false  offset:320213 tailOffset:59505 ",
  "version": 2,
  "waterLogo": "XIAOMI",
  "waterName": "14 Pro"
}
```

livephotoInfo 说明:
- head/time/tail: 系统时钟微秒级时间戳, 总时长 ~3.3s
- filterId: 滤镜 ID
- offset/tailOffset: 摄像头数据流层面偏移量(微秒)
- 合成时可以填 0 占位

## 七、小米相册识别逻辑 (反推)

1. XMP 检查: MicroVideo=1 或 MotionPhoto=1
2. Make="Xiaomi" 检查 -> 激活 Gallery 播放 UI
3. 视频有效性验证: 按 offset/Item:Length 读取尾部 MP4
4. 辅助检查 0x889e -> 更可靠识别

> 最小可行集: XMP + Make/Model
> 推荐: + 0x889e + 0x8895 + 0x9a00

## 八、exiftool 命令参考

```bash
# Make/Model
exiftool -overwrite_original -Make="Xiaomi" -Model="Xiaomi 14 Pro" image.jpg

# 私有标签 (通过 hex ID 写入)
exiftool -overwrite_original   -IFD0:0x9a00="Xiaomi 14 Pro"   -IFD0:0x889d="Madrid"   -IFD0:0x88a3="{}"   -ExifIFD:0x8895="3"   target.jpg

# 0x889e (引号需转义)
exiftool -overwrite_original   -ExifIFD:0x889e='{"buildDevice":"shennong","version":2,"waterLogo":"XIAOMI"}'   target.jpg
```
