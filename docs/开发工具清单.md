## 每个工具怎么用（速查）

### 统一验证入口

所有验证命令从仓库根目录运行。`scripts/verify.ps1` 不打包，也不会清理
`publish/`；它仅编排已有的构建、Native smoke、测试和 CLI 集成步骤。

```powershell
# 日常改动：Native + GUI + CLI 构建，以及 Core/CLI 测试
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1 -Scope Fast

# 额外用 Visual Studio MSBuild 构建完整解决方案
# （Core/CLI 测试已包含在 Fast；当前 UI 测试项目尚无可发现测试）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1 -Scope Full

# 发版前门禁：Full + 真实样本 CLI merge/split/cover/repair 集成测试
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1 -Scope Release -Configuration Release
```

`global.json` 固定 SDK 为 .NET 10.0.400；项目的主产品仍面向 .NET 9，因而
CI 必须同时安装 .NET 9 和 .NET 10 targeting packs。真实样本集成测试仅清理
被 Git 忽略的 `cli-integration-test/` 工作目录，样本源目录不会被修改。
GitHub Actions 没有私有真实样本，因此 PR 使用 `Fast`，`master` 和标签使用
`Full`；打发布标签前仍必须在本机通过 `Release`。
依赖真实设备样本的 Core 测试标记为 `Category=RealSamples`：本机默认运行，
CI 仅排除这一类别，仍执行所有可公开复现的单元与 Native 差分测试。

UI 自动化测试使用 Flawright，标记为 `Category=ManualUI`，因为它需要一个可交互的
Windows 桌面会话。先构建 GUI，再明确指定本次构建产生的可执行文件：

```powershell
dotnet build LivePhotoBox/LivePhotoBox.csproj -c Debug -p:Platform=x64
$env:LPB_UI_TEST_APP_PATH = (Resolve-Path 'LivePhotoBox/bin/x64/Debug/net9.0-windows10.0.19041.0/win-x64/Live Photo Box.exe')
dotnet test tests/LivePhotoBox.UITests/LivePhotoBox.UITests.csproj --filter "Category=ManualUI"
```

它不在无桌面会话的 CI 中自动执行；发布前在本机执行，并在新增关键工作流时扩展同一测试集。

覆盖率收集也统一由脚本执行，结果写入 Git 忽略的 `artifacts/coverage/<timestamp>/`。
安装了 `reportgenerator` 时会额外生成 HTML 和文本汇总；先观察趋势与薄弱模块，再讨论阈值。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/testing/collect-coverage.ps1 -Scope All -Configuration Debug
```

### BenchmarkDotNet
```bash
cd tests/LivePhotoBox.Benchmarks
dotnet run -c Release -- --filter "*"
```
结果在 `BenchmarkDotNet.Artifacts/results/`。加新 benchmark：在 `PathHelperBenchmarks.cs` 加 `[Benchmark]` 方法。

### Everything
```bash
es.exe "关键词"              # CLI 搜索
es.exe -path "目录" "文件名"  # 限定目录搜索
```
GUI：`C:\Program Files\Everything\Everything.exe`

### Flawright
WinUI 3 UI 测试框架。新建测试继承 Flawright API：
```csharp
await using var fw = await Flawright.LaunchAsync(new LaunchOptions { ... });
var page = await fw.Browser.NewPageAsync();
await page.Locator("#Button").ClickAsync();
```

### coverlet + ReportGenerator
```bash
dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=cobertura
reportgenerator -reports:coverage.cobertura.xml -targetdir:coverage-report
```

### Graphify
```bash
cd D:/Projects/live-photo-box
graphify .              # 分析当前目录
graphify query "..."    # 查询代码图谱
```
输出在 `graphify-out/`：`graph.html`（交互图）+ `GRAPH_REPORT.md`（分析报告）

### Sysinternals
```bash
procexp          # 进程浏览器 GUI
procmon          # 进程监控 GUI
pslist exiftool  # 查看 exiftool 进程
```

### fd
```bash
fd "关键词"              # 搜索文件名
fd -e cs "Repair"       # 搜索 .cs 文件
fd -e xaml .            # 列出所有 XAML 文件
```

### Playwright
Web 测试（备用）。用 `InstallAsync()` 下载浏览器：
```csharp
await Playwright.CreateAsync().Result.Chromium.LaunchAsync();
```

## 需要你手动处理的事项

1. **OfficeCLI**：关掉 Windows Defender 实时保护 → 跑 `npm install -g @officecli/officecli`
2. **dotMemory**：去 [JetBrains 官网](https://www.jetbrains.com/dotmemory/) 下载安装
