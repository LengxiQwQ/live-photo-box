## 每个工具怎么用（速查）

### BenchmarkDotNet
```bash
cd tests/LivePhotoBox.Benchmarks
dotnet run -c Release -- --filter "*"
```
结果在 `BenchmarkDotNet.Artifacts/results/`。加新 benchmark：在 `PathHelperBenchmarks.cs` 加 `[Benchmark]` 方法。

### Everything
```bash
es.exe "关键词"              # CLI 搜索
es.exe -path "目录" "文件名"  # 限定目录搜索
```
GUI：`C:\Program Files\Everything\Everything.exe`

### Flawright
WinUI 3 UI 测试框架。新建测试继承 Flawright API：
```csharp
await using var fw = await Flawright.LaunchAsync(new LaunchOptions { ... });
var page = await fw.Browser.NewPageAsync();
await page.Locator("#Button").ClickAsync();
```

### coverlet + ReportGenerator
```bash
dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=cobertura
reportgenerator -reports:coverage.cobertura.xml -targetdir:coverage-report
```

### Graphify
```bash
cd D:/Projects/live-photo-box
graphify .              # 分析当前目录
graphify query "..."    # 查询代码图谱
```
输出在 `graphify-out/`：`graph.html`（交互图）+ `GRAPH_REPORT.md`（分析报告）

### Sysinternals
```bash
procexp          # 进程浏览器 GUI
procmon          # 进程监控 GUI
pslist exiftool  # 查看 exiftool 进程
```

### fd
```bash
fd "关键词"              # 搜索文件名
fd -e cs "Repair"       # 搜索 .cs 文件
fd -e xaml .            # 列出所有 XAML 文件
```

### Playwright
Web 测试（备用）。用 `InstallAsync()` 下载浏览器：
```csharp
await Playwright.CreateAsync().Result.Chromium.LaunchAsync();
```

## 需要你手动处理的事项

1. **OfficeCLI**：关掉 Windows Defender 实时保护 → 跑 `npm install -g @officecli/officecli`
2. **dotMemory**：去 [JetBrains 官网](https://www.jetbrains.com/dotmemory/) 下载安装
