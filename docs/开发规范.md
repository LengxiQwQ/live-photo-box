# Live Photo Box 开发规范

> 本文档是项目开发时的行为规范。当前内容聚焦 CLI 的颜色设计语言；
> 后续的编码、架构、测试约定可继续补充到本节。

## CLI 颜色设计语言

CLI 的所有用户可见文本输出都必须遵守下表配色。目标：**用户扫一眼颜色就能判断
这段内容是什么**——紫色一定是示例代码，草绿一定是路径，黄色一定是数值/名称。

| 内容类型 | 颜色 | 常量（`CliConsole`） | 示例 |
|---|---|---|---|
| 软件名 `Live Photo Box` | 浅红 `RGB(255,140,140)` | `TitleRed` | `--version` / `info` 首行 |
| 标签（冒号前的文字） | 青色 `ConsoleColor.Cyan` | `Accent` | `Protocol:`、`Scanning:`、帮助页标题 |
| 数值 / 版本号 / 数量 / 索引 / 时间戳 / 格式名 / 协议名 | 黄色 `ConsoleColor.Yellow` | `Highlight` | `JPEG+MP4`、`Motion Photo (…)`、`3 pairs`、`#1` |
| 文件 / 目录路径 | 草绿 `RGB(140,205,140)` | `PathGreen` | `C:\...\photo.jpg`、`Output`、`Image`、`File` 行 |
| 示例代码（Usage 行、`lpb xxx` 命令本身） | 紫色 `RGB(180,140,255)` | `CommandPurple` | `lpb merge [options]` |
| 示例代码前的标题 | 青色 `ConsoleColor.Cyan` | `Accent` | `Single pair:`、`Batch folder:` |
| 示例代码后的解释文字 | 白色（默认） | — | `List what formats are available` |
| 描述 / 普通说明文字 | 白色（默认） | — | 帮助页描述、`[default: …]` 之外的内容 |
| `[default: …]` 提示 | 黄色 `ConsoleColor.Yellow` | `Highlight` | `[default: motion photo]` |
| 更新提示文字 | 海蓝 `RGB(102,179,255)` | `Notice` | `A newer version is available`、`You are running the latest version` |
| 成功 `OK` / `✅` | 绿色 `ConsoleColor.Green` | `Success` | 任务成功、`Checking GitHub ... OK` |
| 失败 `FAIL` / `ERROR` / 错误信息 | 红色 `ConsoleColor.Red` | `Error` | 错误提示（必须走 stderr） |
| 取消 `Cancelled` | 灰色 `ConsoleColor.DarkGray` | `Muted` | 用户取消确认 |
| `[DRY RUN]` 提示文本 | 白色（默认） | — | `[DRY RUN] Would merge 1 pair.` |

### 使用规则

1. **黄色只给"数值/名称"类**：数量、索引、版本号、时间戳、格式名（`JPEG+MP4`）、
   协议名（`Motion Photo`）、`Pairing` 值、外部工具版本号。文字说明不要用黄色。
2. **草绿只给"路径"类**：文件、目录、输出路径。提示语里内嵌的路径也要单独上草绿。
3. **紫色只给"示例代码"本身**：Usage 行整行、描述行中的 `lpb …` 命令段。
   示例代码前面的标题用青色（标签色），后面的解释用普通白色，
   保证"看到紫色就知道是示例代码"。
4. **标签一律青色**：`WriteField` / `WriteFieldRgb` 输出的冒号前文字。
5. **错误信息一律红色且输出到 stderr**：用 `CliConsole.WriteErrorLine`。
6. **终端不支持颜色时自动降级**：stdout 被重定向（管道/文件/CI）或设置了
   `NO_COLOR` 环境变量时，所有颜色输出自动退化为纯文本，布局不变。

### 技术实现

- 颜色常量与辅助方法集中在 `LivePhotoBox.CLI/Infrastructure/CliConsole.cs`：
  - `WriteField(label, value, width, valueColor)`：值用 `ConsoleColor` 着色；
  - `WriteFieldRgb(label, value, width, valueColor)`：值用 24 位 RGB 真彩色着色
    （海蓝、草绿、紫色等）。
- `CliConsole.UseColor`：`!Console.IsOutputRedirected && NO_COLOR 未设置` 时启用颜色。
- 帮助页着色逻辑在 `LivePhotoBox.CLI/Infrastructure/GroupedHelpBuilder.cs`：
  标题青、选项/参数第一列草绿、`[default: …]` 黄、示例代码紫、解释白。
- 演示脚本 `scripts/cli-color-demo.cmd` 会跑一遍所有带颜色的输出，
  改完颜色后建议用它做全量目检。

### 反面示例（禁止）

- 把整行描述（标题 + 示例代码 + 解释）全部涂成紫色；
- 把路径涂成黄色或把数值涂成草绿；
- 在非交互终端里依赖颜色传递信息（重定向时会丢失）。
