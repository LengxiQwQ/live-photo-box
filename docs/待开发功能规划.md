## 1. CLI 命令行工具（AI 接口）

> ✅ **已交付（v2.1.1）**。作为独立工程 `LivePhotoBox.CLI` 交付（可执行名 `livephotobox`），与 GUI 共享 100% 核心逻辑（`LivePhotoBox.Core`）。

最初规划新增 .NET 控制台应用，引用现有 Services 层，编译为独立 exe，让 AI Agent 和高级用户能通过终端调用核心功能——现已落地，实际命令集以 `merge` / `protocols` / `update-check` 为准：

```
livephotobox merge -i a.jpg -vid a.mov -o out -p huawei -f heic+mp4-h265
livephotobox merge -d "D:\Photos\" --pairing cid --after move:D:\整理
livephotobox protocols
livephotobox update-check
```

- 框架：.NET 控制台应用 + System.CommandLine（6 个可执行别名：`livephotobox` / `livephoto` / `livebox` / `lipbox` / `lpb` / `lpbx`）
- 单对合成 + 批量合成（按文件名 / Apple `ContentIdentifier` UUID / vivo 相机 ID 配对）
- 命名模板、并行度 `-j`、`--dry-run`、`-y`、`--overwrite`、`--recursive`、`--preserve-subdirs`、`--after`（移动文件夹 / 回收站）
- 安装版用户：CLI exe（`livephotobox` 及别名）由 Inno Setup 可选注册到 PATH
- 商店版用户：仅通过 GUI 操作
- 使用文档：`docs/CLI-User-Guide.zh-CN.md` / `docs/CLI-User-Guide.md`

> 原规划的 `combo/split/repair/edit/scan` 命令集未采用（`combo` 最终命名 `merge`）；拆分 / 修复 / 编辑 / 扫描仍为 GUI 专属。

## 2. 编辑页面功能增强

当前编辑页以封面帧选取为主，后续扩展为单张实况照片的全功能操作中心：

- [x] **视频轨道静音**：已交付 —— 编辑页可静音/取消静音，跨会话持久化
- [x] **多种格式导出**：已交付 —— 封面帧导出 JPEG / PNG / WebP / BMP / TIFF / HEIC；可导出全部帧、导出视频（MP4/MOV）、导出 GIF（动图，可调尺寸/帧率/循环）
- [ ] **单张合成**：在编辑页内直接选图片 + 视频素材，合成为单张实况照片（当前在合成页完成）
- [ ] **单张拆分**：一键将当前实况照片拆分为独立图片 + 视频（当前在拆分页完成）
- [ ] **单张修复**：快速修复当前照片的显示异常（缩略图拉伸、方向错误等）（当前在修复页完成）

## 4. 样例照片图床化

当前仓库带有样例照片体积较大，改为：

- 样例素材上传到 GitHub 外部存储（Releases / 独立仓库）
- 应用首次启动或用户点击「下载样例」时按需拉取
- 本地仅保留占位缩略图或下载缓存标记
- 减少仓库体积和克隆时间

## 5. UI 框架变更 —— 三面板布局

去掉传统 WinUI 页面底色/背景面板设计，改为 **3 面板拼接布局**：

- **左面板**：文件列表/资源浏览树
- **中面板**：主操作区（预览/编辑/参数设置）
- **右面板**：信息详情/任务状态

优势：
- 视觉更简洁统一
- 主操作区更宽敞
- 各页面布局一致，减少切换割裂感
