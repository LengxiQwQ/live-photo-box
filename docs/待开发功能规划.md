## 1. CLI 命令行工具（AI 接口）

在解决方案中新增 .NET 控制台应用项目，引用现有 Services 层，编译为独立 exe，让 AI Agent 和高级用户能通过终端调用核心功能。

```
livephotobox combo --image a.jpg --video a.mov --output result.heic
livephotobox split --input photo.heic
livephotobox repair --dir "D:\Photos\"
livephotobox edit cover --input photo.heic --frame 1.5
livephotobox scan --path "D:\Photos\"
```

- 框架：.NET 控制台应用 + System.CommandLine
- 安装版用户：CLI exe（`livephotobox.exe` 及别名）由 Inno Setup 注册到 PATH
- 商店版用户：仅通过 GUI 操作
- 完成后需编写 SKILL.md 供 AI Agent 文档参考

## 2. 编辑页面功能增强

当前编辑页以封面帧选取为主，后续扩展为单张实况照片的全功能操作中心：

- **单张合成**：在编辑页内直接选图片 + 视频素材，合成为单张实况照片
- **单张拆分**：一键将当前实况照片拆分为独立图片 + 视频
- **单张修复**：快速修复当前照片的显示异常（缩略图拉伸、方向错误等）
- **视频轨道静音**：替换实况照片的视频音轨为静音，或移除音频
- **多种格式导出**：支持导出封面帧为 PNG / GIF（动图）等常见格式

## 3. 批量处理改造

将现有的合成/拆分/修复页面统一改造为批量操作入口：

- 支持拖入或选择多个文件/文件夹
- 批量选择后统一设置参数（目标协议、输出目录、编解码选项等）
- 批量任务队列 + 进度显示 + 完成后通知
- 拆分页面：批量将一批实况照片拆分为图片 + 视频
- 修复页面：批量扫描并修复一批文件
- 合成页面：批量配对图片 + 视频进行合成

## 4. 样例照片图床化

当前仓库带有样例照片体积较大，改为：

- 样例素材上传到 GitHub 外部存储（Releases / 独立仓库）
- 应用首次启动或用户点击「下载样例」时按需拉取
- 本地仅保留占位缩略图或下载缓存标记
- 减少仓库体积和克隆时间

## 5. UI 框架变更 —— 三面板布局

去掉传统 WinUI 页面底色/背景面板设计，改为 **3 面板拼接布局**：

- **左面板**：文件列表/资源浏览树
- **中面板**：主操作区（预览/编辑/参数设置）
- **右面板**：信息详情/任务状态

优势：
- 视觉更简洁统一
- 主操作区更宽敞
- 各页面布局一致，减少切换割裂感
