# Live Photo Box 快捷键说明

本文档介绍 Live Photo Box 图形界面当前提供的键盘快捷键。快捷键主要用于“编辑”“合成”“拆分”和“修复”页面，帮助用户连续浏览资源、管理任务队列以及快速完成保存、导出和处理操作。

## 使用前须知

- 每组页面快捷键只在对应页面生效，切换页面后不会继续接管键盘。
- 当光标位于路径框、搜索框、下拉框、数值框、滑块等输入控件中时，软件会保留控件原本的键盘操作，不触发页面快捷键。
- 某项功能不可用时，对应快捷键也不会执行。例如当前文件没有可播放的实况视频时，按空格键不会产生操作。
- `Ctrl`、`Shift`、`Alt` 表示需要按住该键，再按组合中的其他按键。
- `+` 和 `-` 同时支持主键盘与数字小键盘；主键盘的 `+` 与 `=` 共用一个按键，因此按 `=` 也可以放大。

## 资源与时间轴导航

| 快捷键 | 功能 | 使用条件或说明 |
|---|---|---|
| `↑` | 选择上一个资源 | 在左侧资源浏览区切换文件 |
| `↓` | 选择下一个资源 | 在左侧资源浏览区切换文件 |
| `←` | 选择时间轴上一帧 | 当前文件具有可用时间轴 |
| `→` | 选择时间轴下一帧 | 当前文件具有可用时间轴 |
| `Home` | 跳转到时间轴第一帧 | 当前文件具有可用时间轴 |
| `End` | 跳转到时间轴最后一帧 | 当前文件具有可用时间轴 |
| `K` | 前往当前封面 | 跳转到当前封面照片对应的帧 |
| `O` | 前往原始封面 | 当前实况照片保留了可识别的原始封面帧 |

方向键由编辑页面统一处理，操作完成后焦点会回到资源浏览区，便于连续切换文件和帧，也可避免外层导航栏抢占方向键。

## 预览与播放

| 快捷键 | 功能 | 使用条件或说明 |
|---|---|---|
| `Space` | 播放实况照片 | 当前资源具有可播放的实况视频 |
| `M` | 静音或取消静音 | 当前资源具有可播放的实况视频 |
| `+` 或 `=` | 放大预览 | 等同预览区右上角的放大按钮 |
| `-` | 缩小预览 | 等同预览区右上角的缩小按钮 |
| `0` | 恢复适应窗口 | 重置缩放与平移，使内容重新适应预览区域 |
| `F11` | 最大化或还原预览 | 在普通编辑布局与最大化预览之间切换 |
| `Esc` | 停止播放或退出最大化 | 优先停止正在播放的实况照片；未播放时退出最大化预览 |

## 文件、保存与导出

| 快捷键 | 功能 | 使用条件或说明 |
|---|---|---|
| `Ctrl` + `O` | 选择资源文件夹 | 打开文件夹选择窗口并扫描所选目录 |
| `F5` | 刷新资源文件夹 | 当前路径必须是有效文件夹；不会在路径无效时清空列表 |
| `C` | 清除目录 | 清空当前目录、资源列表和预览 |
| `Ctrl` + `S` | 设为封面并保存为副本 | 当前时间轴帧可以被设为封面 |
| `Ctrl` + `Shift` + `S` | 另存为 | 当前已选择文件 |
| `Ctrl` + `E` | 导出当前帧 | 当前帧可导出 |
| `Ctrl` + `Shift` + `E` | 导出所有帧 | 当前文件具有可导出的时间轴 |
| `Alt` + `E` | 打开导出菜单 | 可继续选择导出帧、视频或 GIF |

## 常见情况

### 按快捷键没有反应

先确认当前位于“编辑”页面，并且对应的按钮在界面中处于可用状态。如果正在路径框或搜索框中输入文字，请先单击资源列表或预览区域，再使用页面快捷键。

### 方向键仍在输入框中移动光标

这是预期行为。输入控件获得焦点时，方向键会保留给文字光标、下拉选项或滑块使用；离开输入控件后，方向键恢复为资源与时间轴导航。

### `Esc` 为什么没有退出最大化预览

如果实况照片正在播放，第一次按 `Esc` 会优先停止播放；再按一次即可退出最大化预览。

## 快捷键设计说明

快捷键以连续编辑效率为核心：上下键负责资源，左右键负责帧，单字母键负责预览中的即时动作，带 `Ctrl` 的组合键负责文件与输出操作。所有快捷键都复用界面按钮原有功能及可用状态，不会绕过保存、导出或文件有效性检查。

## 合成页面

### 文件夹与任务操作

| 快捷键 | 功能 | 使用条件或说明 |
|---|---|---|
| `Ctrl` + `O` | 添加文件 | 合成输入配置可编辑时 |
| `Ctrl` + `Shift` + `O` | 选择输入目录 | 选择目录后按页面原有逻辑扫描 |
| `Alt` + `O` | 选择输出目录 | 合成输出配置可编辑时 |
| `Ctrl` + `Shift` + `I` | 打开输入目录 | 当前输入目录可以打开时 |
| `Ctrl` + `Shift` + `E` | 打开输出目录 | 当前输出目录可以打开时 |
| `F5` | 扫描或重新扫描输入目录 | 仅在未扫描、未合成时启动扫描 |
| `C` | 清空任务队列 | 仅在空闲状态生效 |
| `Ctrl` + `F` | 聚焦任务搜索框 | 可以直接输入文件名筛选任务 |

### 合成控制

| 快捷键 | 功能 | 使用条件或说明 |
|---|---|---|
| `Ctrl` + `Enter` | 开始合成 | 只负责开始，不会在处理中变成停止操作 |
| `P` | 暂停或继续合成 | 仅在正在合成时生效 |
| 连按两次 `Esc` | 停止扫描或合成 | 两次按键必须在 1 秒内完成；第一次不会停止 |

### 任务队列导航

| 快捷键 | 功能 | 使用条件或说明 |
|---|---|---|
| `↑` | 选择上一个任务 | 队列中的当前任务会显示选中视觉 |
| `↓` | 选择下一个任务 | 队列中的当前任务会显示选中视觉 |
| `Enter` 或 `Space` | 在灯箱中预览当前任务 | 必须先选中任务 |
| `Delete` | 从队列移除当前任务 | 仅在空闲状态生效，不删除源文件 |

### 页面入口

| 快捷键 | 功能 |
|---|---|
| `F1` | 打开合成操作引导 |
| `Ctrl` + `,` | 打开合成相关设置 |

合成过程中，`Ctrl` + `Enter` 不会切换成停止操作。停止必须在 1 秒内连续按两次 `Esc`，以降低任务无法继续时的误操作风险。
