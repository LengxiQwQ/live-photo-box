# Live Photo Box 编辑页导出流程 — 自动化演示

脚本位于 `scripts/Python_Scripts/demo_export.py`。
一键自动化「编辑页 → 载入华为实况 → 导出为视频 → 验证」全流程，
用于演示/回归测试编辑页导出功能。已实测跑通（见下文验证记录）。

## 前置依赖
- **WinApp 自动化驱动**（已全局安装，`server/WinAppMCP.exe`）——驱动 WinUI 桌面应用
- **ffmpeg / ffprobe**（应用自带 Tools，或系统 PATH）
- 应用可运行（脚本会自动启动 Debug 构建）

## 用法
```
python demo_export.py
```
跑完输出一份 `RESULT JSON`，关键字段：
- `live_detected` / `timeline_loaded` — 文件是否被识别为实况、时间轴是否生成
- `save_dialog` — 系统保存对话框是否弹出
- `export_done` / `output_file` — 导出是否完成、产物路径
- `VERDICT` — **PASS/FAIL 结论**

## 流程（对应编辑页操作）
1. 启动应用，进入「实况照片编辑」页
2. 在「当前目录」输入框填入文件夹路径 → 点刷新按钮
3. 在文件列表选中华为实况文件（第一项）
4. 等待时间轴从内嵌视频提取完成
5. 点「导出…」菜单 → 触发「导出为视频」
6. 操作系统保存对话框（ctypes 定位 + 填文件名 + 回车确认）
7. 动态扫描最近生成的视频文件 → ffprobe 验证是否为真实运动视频（多帧）

## 自定义
脚本顶部 `CONFIG` 可改：
- `app_exe` — 应用可执行文件路径
- `folder` — 含实况照片的文件夹
- `out_mp4` — 期望输出路径（保存对话框可能改用建议名存到默认目录，脚本会动态扫描兜底）

## 注意事项
- 保存对话框自动化依赖 Windows 经典「另存为」对话框结构；若对话框未弹出，
  `save_dialog` 会显示 NOT FOUND，可手动确认。
- 脚本每次会杀掉自己启动的自动化驱动进程，不影响应用本体。
- 运行方式：`python scripts/Python_Scripts/demo_export.py`（默认配置指向 `_ai-tmp/hw_drive` 测试文件夹，按需修改脚本顶部 `CONFIG`）。
