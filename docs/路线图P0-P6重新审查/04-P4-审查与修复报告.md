## 3. 架构与行为影响

CMake 仍是 canonical Native 构建入口，vcpkg baseline 固定。JPEG 使用 libjpeg-turbo；HEIC 使用 libheif/libde265/x265；container/vendor truth 由项目代码负责。最终 Managed 发布复用既有 `WindowsOwnedFilePublisher`，没有新增第二套 rename/rollback 实现。

视频执行遵循 [P7-R4 决策](../LivePhotoBox-Current-Roadmap/LivePhotoBox-P7-细分路线图/P7-R4-HEVC-backend-decision.md)：Copy/remux 使用项目 ISO-BMFF，普通 SDR H264→H264 使用 MF，涉及 HEVC 或适用 10-bit/HDR 重编码使用 pinned minimal-libav sidecar；没有失败后隐藏 fallback。

源/输出目录链含 Junction/reparse、源已有写句柄、转换输出被替换或改写时明确拒绝，符合现行 fail-closed 规则。新增测试包含具体源读取诊断，避免其他异常冒充拦截成功。UI 的 Magick/PhotoSauce 预览用途继续保留；Native 不因单纯 ICC 字节保留引入 lcms2。
