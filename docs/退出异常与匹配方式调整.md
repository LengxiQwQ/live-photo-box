## 匹配入口与兼容决策

- 合成页原“匹配方式”保留文件名、Apple CID、vivo ID，追加“严格匹配（文件名 + 协议）”。严格模式仍以同目录同名选择候选，并要求原生确认的源实况双文件身份；普通图+视频仍可通过原文件名模式发起合成。
- 拆分页原“匹配方式”保留所有已支持协议，追加文件名匹配。此模式只选同目录同名双文件，继续要求 Apple/vivo 原生源配对证明；普通图+视频不能伪装成可拆分实况。单文件实况继续通过协议选项识别。文件名模式不作为协议失败后的回退。
- 沿用 `PairingMethodIndex`（默认0）与 `SplitMatchProtocolIndex`（默认0），新索引追加，既有索引语义和默认值不变；两页互不改变对方，扫描参数在开始前捕获，执行中不能改输入配置。异常索引安全回到既有默认。
- 设置页“更严格的实况照片扫描”入口及首页对应跳转移除。源码核对发现旧 `IsStrictLivePhotoScanEnabled` 实际只由修复页读取，未控制合成/拆分，因此不能把旧 true 强行迁移为两页新策略。保留旧键/修复读取及默认 false，避免改变既有修复行为；不再提供重复设置入口。本轮不改修复页匹配语义。
- 定向回归发现基线存在按扩展名/顺序挑选同名成员、重复 CID 先挑一对再报剩余问题的行为；本轮按明确要求取消猜配。多候选组整体给出歧义诊断，独立文件继续。此项有意收紧有歧义输入；CLI 正常唯一配对及默认策略不变。
- 中英文资源、下拉提示、标签关联和可访问性 ID 同步；未实现的 Fusion 仍隐藏。
